# 新しい主チャットからの開始文

新しい主チャットでは、例えば次の形で要求を渡す。これは製品開発の開始例であり、
指示文書の導入・編集だけの依頼中には実行しない。

```text
このリポジトリの docs/ai-instructions/tdd-context/run.md を入口に、次の要求を進めてください。

要求：〈今回の要求〉

Red、Green、Refactorを、親の会話履歴を継承しない工程担当で順番に進めてください。
この要求の範囲で担当の起動と成果物の一方向の受け渡しを許可します。
担当同士の相談、工程間のAIレビュー・AI承認は不要です。
既存の作業ツリーと差分を保全し、コンテキスト分離のためにworktreeを作り直さないでください。

Green後と実変更を伴うRefactor後は、未コミット差分を私が確認します。
対象ファイルとメッセージ案を示し、了承後にそれぞれG/Fコミットを作成してください。
Refactor変更なしならFコミットや空コミットは不要です。
未決定の外部契約が不可欠な場合は、判断事項を示して停止してください。
```

# AIの作業記録

AIによる調査・作業計画・引継ぎの置き場です。Gitで管理し、確定仕様や作業指示の正本とは区別します。

## 記録先と再開順

再開時は[現在の作業状況](current-work.md)をGit状態と照合し、今回関係する仕様・判断と候補を確認します。

| 記録 | 用途 |
| --- | --- |
| [現在の作業状況](current-work.md) | 停止位置、未コミット差分、検証結果、次の着手点 |
| [開発候補](development-candidates.md) | 調査結果、未確定事項・検討候補と対応状況。掲載は実装許可ではない |
| [開発の仕様と判断](../docs/development-context.md) | 確定した方針、判断理由・不採用理由、仕様と根拠の参照先 |
| [測定記録](../Kotowari.Benchmarks/Results/README.md) | 測定条件・結果・判断根拠 |

## 整理の手順

追加・更新・再開・中断時は[AGENTS.mdの「記録の整理と維持」](../AGENTS.md#記録の整理と維持)に従います。移設した場合はこの一覧と参照元を更新します。記録を別の場所へ複製しません。

利用・開発文書や長く残す設計判断は `docs/` 等の既存資料、指示は既存の `docs/ai-instructions/` に置きます。一時実験・生成物・生ログは既存の無視対象へ置き、この場所に秘密情報や端末固有の絶対パスを残しません。
